## Порядок работ

0. **Изоляция эффектов cvar'ами игры** (`DM_DOOM_ARGS`): `+set r_antialiasing 0` (TAA → ореолы/шлейфы?), `+set r_skipFog 1`
   (пелена = туман?), `+set r_motionblur 0`, `+set r_SSDOTemporalAA 0`. Сразу показывает, какой проход ломается.
1. **Быстрые A/B по переключателям** (diag_run: взгляд вниз/вверх + стояние 90 с со скриншотами):
   - `DM_GFX_PARTIAL_TEX=0` (без частичных загрузок текстур) — лоды (1b), туман (3D-объём);
   - `DM_GFX_EARLY_Z=0` — feedback VT (1a), туман, дыры;
   - `DM_GFX_DEPTH_FEEDBACK=0`, `DM_GFX_ZEROCOPY=0` — туман/дыры;
   - что помогло → в дефолт, затем чинить сам механизм.
2. **Прицельный прогон VT**: счётчики вызовов NVN в игре (DM_NVN_COUNT/PROF) — через что игра обновляет физический кэш
   и таблицу страниц (WriteTexels / копии / compute `updatepagetablemip`), и проследить чтение feedback CPU (`cpu_access`, events).
3. **Туман**: дамп кадра (gfx-dump-now) с видом в пол — пирамида глубины, froxel-объём, проход тумана.
4. **Дыры**: сравнение prepass и G-buffer по дампу; выключить lone-rewrite для GS-куллинга; барьер между prepass и G-buffer.
5. **Разрывы проходов по мипам/слоям** (подресурсы) — производительность.
6. Вибрация, vmtr.
